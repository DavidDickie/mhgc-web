# MHGC web port: rules-vs-code decisions

Stage 1, 2026-11-12. Applies Dave's rulings of 2026-11-12:

- The rules document (`~/mhgc/mhgc_rules.txt`, v3.1, 2013) is gospel.
- Where the C code (Nov 2008) disagrees with the rules, the rules win.
- Where the rules are silent or ambiguous, the C code's formulas, tables and behaviour are used.
- Bugs are fixed, not reproduced. There is no bit-exact replication.

References: `rules:N` is a line in the rules, `E5-n` is item n of ENGINE_MAP §5, and `file.c:N` points into the pristine C. Implementation pointers name the module that carries the decision.

Resolution codes:

| Code | Meaning |
|---|---|
| **R** | rules win |
| **C** | code behaviour kept (the rules are silent or ambiguous) |
| **X** | C bug fixed |
| **W** | web-game decision (Dave, 2026-11-12) |
| **N** | new behaviour, needed because neither source covers it |

### 1.1 Rules-over-code changes that alter play noticeably

These aren't ambiguities: the rules are clear, so they win. They are listed so that Dave can review the game feel.

- **System weapons fire in space combat.**
  - PD subtracts 1 and SW subtracts 5 from each hostile empire's attack.
  - SW (1) and APD (5) attack for the owner.
  - The C had this whole block commented out (gccombat.c:306-466).
- **Militia use starport capacity** like other CTs: 2 per class (rules:441-444). The C exempted them. Militia still can't outnumber population.
- **Mixed Fleet Bonus applies to attack only** (rules:819-833). The C also multiplied defence.
- ~~**NPRs aren't ranked.**~~ Superseded by A-06 (Dave 2026-11-15): every race is ranked, the stat-bonus VP are over all races, and computer empires can win.
  - ~~Stat-bonus VP and ranks are among human players only (rules:238-239).~~
  - ~~Victory is for humans.~~
- **Raids** follow the rules' 5-point and 25-point arithmetic.
  - Starports aren't a raid target.
  - The C divided raid points by 5 first, so small raids did nothing.
- **Salvaging a CT returns 50%** (rules:606, 2289). The C returned 75%.
- **Entrenched troops attack at half** (rules:591). The C gave them no attack.
- **Fleet speed**: the slowest ship in the main body, or the FS setting. The C used the rounded average and ignored FS.
- **Uprisings**: 50% when Unhappy, 10% when Not Happy, militia 1 in 10. **Emperor day**: 10% when Very Happy, 50% when Extremely Happy.
- **Spy odds** follow the rules table (SAL 30/30, SSB 20/40, SET 20/40). Counter-intelligence applies to every mission.
- **Base production** is 5 per pop with no leader (rules:352, 412-421). The C halved it. The relative effect of leaders is unchanged (D-02).
